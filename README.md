# 네이버 카페 URL 업무 자동화 도구

### Cafe URL Workflow Automation

![.NET](https://img.shields.io/badge/.NET-8.0-purple)
![C#](https://img.shields.io/badge/C%23-WinForms-blue)
![License](https://img.shields.io/badge/License-MIT-green)

> 여자친구의 반복 업무를 조금이라도 덜어 주고 싶어서 만든 **업무 자동화
> 프로젝트**입니다.

`Monthly Excel`은 네이버 카페 게시글 URL을 기반으로 필요한 정보를
수집하고\
그 결과를 엑셀로 정리할 수 있도록 만든 **WinForms 기반 데스크톱 자동화
도구**입니다.

단순한 크롤러가 아니라 **실제 반복되던 업무 흐름을 줄이기 위해 만든
실사용 프로젝트**입니다.

------------------------------------------------------------------------

# Why I Built This

여자친구 회사에서는 네이버 카페 게시글을 하나씩 열어 보고

-   조회수
-   댓글 수
-   작성일

같은 정보를 확인한 뒤 다시 **엑셀 양식에 직접 입력하는 작업**을 반복하고
있었습니다.

이 작업은 익숙하지만 반복될수록

-   시간이 오래 걸리고
-   단순 입력 과정에서 실수 가능성이 생기며
-   피로도가 높아지는 문제

가 있었습니다.

그래서 **URL만 준비하면 필요한 정보를 자동으로 수집하고 엑셀로 정리하는
도구**를 만들었습니다.

------------------------------------------------------------------------

# Features

### 카페 URL 데이터 수집

네이버 카페 게시글 URL을 기반으로

-   조회수
-   댓글 수
-   작성일

등 필요한 정보를 자동으로 수집합니다.

------------------------------------------------------------------------

### 엑셀 결과 정리

수집된 데이터를 **엑셀 템플릿 형태로 자동 정리**합니다.

반복적으로 입력하던 작업을 줄이고 정리 시간을 단축합니다.

------------------------------------------------------------------------

### 키워드 분리 도구

엑셀 또는 텍스트에서 복사한 키워드를

-   자동 분리
-   리스트 정리

기능을 통해 정리할 수 있습니다.

------------------------------------------------------------------------

### 블로그 본문 정리

WebView2를 이용해

-   블로그 본문 정리
-   불필요 요소 제거
-   이미지 저장

기능을 제공합니다.

------------------------------------------------------------------------

# Result

이 도구를 통해

-   반복 입력 시간을 줄이고
-   업무 피로도를 낮추며
-   단순 작업을 자동화

할 수 있었습니다.

기술적인 목적보다 **실제 주변 사람의 문제를 해결하기 위해 만든
프로젝트**라는 점에서 더 의미가 컸습니다.

# Distribution

여자친구 회사 컴퓨터에서는 **설치형 프로그램 배포가 어려운 환경**이라\
포터블 방식으로 사용하고 있습니다.

빌드 후 생성되는

    bin/Debug
    또는
    bin/Release

폴더를 그대로 전달하여 실행합니다.

별도 설치 과정 없이 **바로 실행 가능한 방식**으로 운영하고 있습니다.
